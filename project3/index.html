A.2: Homography Matrix Computation

To recover the homography between two images, I manually selected corresponding points on the same planar surface. Using these points, I built a system of equations based on the Direct Linear Transform (DLT) method. I solved for the best-fit homography matrix H using least squares and normalized it so that the bottom-right value is 1. This matrix allows mapping points from one image to the other through a projective transformation.

Equations
Homography relation:
H · [x, y, 1]^T = [u, v, 1]^T

System of equations for each correspondence (x, y) ↔ (u, v):
[-x, -y, -1,  0,  0,  0, x·u, y·u, u]
[ 0,  0,  0, -x, -y, -1, x·v, y·v, v]

Solve for h in A·h = 0 using least squares (SVD):
h = last column of V (from SVD of A)

Reshape to get 3×3 homography matrix H:
H = [[h1, h2, h3],
     [h4, h5, h6],
     [h7, h8,  1]]

A.3: Warp the Images

To warp each image, I implemented inverse warping using both nearest neighbor and bilinear interpolation. Given a homography matrix H, I used its inverse to map every pixel in the output image back to its corresponding position in the source image. Nearest neighbor uses the closest pixel value, while bilinear interpolation averages the four surrounding pixels for smoother results. I applied this to two rectification examples, a book and a refrigerator, to transform the perspective so that the selected planar surfaces appear front facing.

Equations
Inverse warping:
[x, y, 1]^T = H⁻¹ · [x', y', 1]^T

Nearest Neighbor:
I'(x', y') = I(round(x), round(y))

Bilinear Interpolation:
I'(x', y') = (1 - dx)(1 - dy)·I(x0, y0)
            + dx(1 - dy)·I(x1, y0)
            + (1 - dx)dy·I(x0, y1)
            + dx·dy·I(x1, y1)

Nearest Neighbor vs. Bilinear Interpolation

The results show that nearest neighbor and bilinear interpolation produce noticeably different outcomes. Nearest neighbor warping runs faster because it simply picks the closest pixel, but it often leads to blocky textures and jagged edges. Bilinear interpolation is slower since it averages surrounding pixel values, yet it produces smoother, sharper, and more realistic results. The tradeoff is clear: nearest neighbor is better for speed, while bilinear interpolation offers higher visual quality and cleaner rectifications, especially for detailed or text heavy images.

A.4: Blend the Images into a Mosaic

I created three panoramas using weighted averaging to reduce seams. After estimating a homography for each pair, I inverse warped the source image onto the reference canvas, built a soft mask, and blended the overlapping regions with a feathered alpha so edges fade smoothly.

Procedure
  1. Estimate the homography from the clicked correspondences.
  2. Inverse warp the source image into the reference frame and record a binary valid mask.
  3. Convert the binary mask into a soft alpha using a cosine falloff toward the borders.
  4. Blend overlapping pixels with weighted averaging; then crop to the union of valid pixels.
Blending formula
I_out = (α_ref · I_ref + α_src · I_src) / (α_ref + α_src + ε)
α_src = soft mask on the warped image
α_ref = ones on the reference image (or a soft mask if desired)
